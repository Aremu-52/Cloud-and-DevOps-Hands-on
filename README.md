A practical Cloud and DevOps project demonstrating the complete journey from infrastructure provisioning to containerization, container registry, and CI/CD automation.

The project follows this workflow:

Terraform → Ansible → Docker → Amazon ECR → GitHub Actions → Deployment

Project Goal

The goal of this project is to gain practical experience building and automating a cloud deployment environment.

Instead of manually configuring everything, the project demonstrates how DevOps tools can be used to:

Provision cloud infrastructure automatically
Configure servers automatically
Containerize applications
Store Docker images in Amazon ECR
Automate builds and deployments with GitHub Actions
Deploy an application to AWS
Create a reusable deployment workflow for future applications
